# AGENTS.md — Семейный список

## О проекте
Семейный список фильмов, книг и настольных игр: что хотим посмотреть, прочитать или сыграть и что уже готово, с оценкой. Для нашей семьи, с телефона и компьютера.
Файлы: index.html — разметка, styles.css — вид, script.js — логика.
Требования к функциям — в папке specs/. Описание для людей — в README.md.

## Правила
- Только HTML, CSS и JavaScript в этой папке. Без npm, библиотек и внешних ресурсов — страница должна работать без интернета.
- Данные храни в браузере (localStorage). Ничего не отправляй в интернет.
- Интерфейс на русском языке, подписи короткие и понятные.
- Кнопки и поля не меньше 44px, страница работает на телефоне шириной 375px.
- Делай только то, о чём попросили. Работающие функции не ломай.
- Список — три колонки: «Фильмы», «Книги», «Игры». Каждая запись — одна компактная строка: галочка, название, звёзды, кнопка ✕.
- Оценка — от 1 до 5 звёзд (★★★★☆), ставится кликом по звёздам и только после галочки «Просмотрено» / «Прочитано» / «Играли». Без галочки звёзды неактивны и показывай «не оценено». Название не может быть пустым — покажи подсказку.
- Не добавляй запись, если такое же название уже есть в этой колонке (без учёта регистра) — покажи подсказку «Уже есть в списке».

## Git
- Когда шаг готов, спроси «Коммитим?». Только после моего «да» — git add, git commit и git push.
- Без моего «да» — ни одного коммита: сначала я проверяю работу сама.

## Новая функция
- Каждую новую функцию начинай с файла specs/NNN-nazvanie.md. NNN — следующий номер: 001, 002, 003. Название — латиницей через дефис.
- Разделы файла: Для кого и зачем; Что должно быть; Примеры; Ограничения; Готово, когда.
- Пока я не написала «делай», код не пиши.
- Когда функция готова, обнови README.md: что умеет страница и как проверить.

## Большая функция
- В конце specs/NNN добавь раздел «Шаги»: каждый шаг — одна вещь на экране и проверка числами или примером, с галочкой [ ].
- Делай только один шаг за раз: сделал → поставь [x] в «Шагах» → спроси «Коммитим?».
- Следующий шаг — только когда я напишу «делай шаг N».

## Как проверить
- Открыть index.html двойным щелчком.
- Добавила «Дюна» (фильм), «Мастер и Маргарита» (книга), «Каркассон» (игра) → каждая в своей колонке, сверху.
- Без галочки у «Дюны» звёзды неактивны и «не оценено»; поставила галочку и 5 звёзд → видно ★★★★★.
- Удалила запись через ✕ → спросило «Удалить?», запись пропала.
- Добавила «Моана» второй раз → подсказка «Уже есть в списке».
- После F5 всё на месте.
