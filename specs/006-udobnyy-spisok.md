# Удобный список

## Для кого и зачем
Для семьи, которая ведёт общий список и хочет быстрее добавлять записи, находить нужное, видеть только свои незавершённые планы, выбирать порядок списка и получать случайную идею на сегодня.

## Что должно быть
- Форма добавления содержит поле названия, выбор типа и кнопку «Добавить». На мониторе эти элементы стоят в одну строку; на экране шириной 375px — друг под другом.
- Над тремя колонками есть поле поиска. Оно фильтрует записи во всех колонках по части названия без учёта регистра.
- Счётчик каждой колонки показывает число записей, которые сейчас видны после поиска, фильтра и сортировки.
- Есть переключатель «Только неотмеченное». Он скрывает записи, которые отметил выбранный сейчас участник, и сохраняет своё состояние после F5.
- Есть выбор сортировки: «Сначала новые» по умолчанию, «По названию А–Я» и «По оценке». Выбранный порядок сохраняется после F5.
- Кнопка «Что посмотреть сегодня? 🎲» выбирает случайную запись из всех трёх колонок, которую текущий участник ещё не отметил, и показывает её крупно.
- В результате случайного выбора есть кнопка «Ещё вариант», которая выбирает другой случайный подходящий вариант.
- Если текущий участник отметил все записи, вместо результата видно «Всё уже посмотрели!».
- Поиск, переключатель и сортировка применяются одновременно; при этом галочки, оценки, участники, проверка дублей и удаление записей продолжают работать как раньше.

## Примеры
- На мониторе поле названия, тип и «Добавить» занимают одну строку; на телефоне шириной 375px они расположены один под другим, а список начинается выше, чем до изменения.
- Ввести «моа» в поиск — во всех колонках остаётся видна только «Моана»; очистить поле — снова видны все записи.
- Айнур отметила «Моану»: при включённом «Только неотмеченное» «Моана» скрыта для Айнур; выключить переключатель — она снова видна. После F5 переключатель остаётся включённым.
- При «По названию А–Я» «Ангелы и Демоны» находится выше «Моаны». После F5 выбранный вариант сортировки остаётся выбранным.
- При нажатии «Что посмотреть сегодня? 🎲» показывается крупно одна неотмеченная Айнур запись, например «Книги: Мастер и Маргарита». Нажать «Ещё вариант» — показывается другая подходящая запись. Если все записи отмечены Айнур, видно «Всё уже посмотрели!».

## Ограничения
- Использовать только HTML, CSS и JavaScript без библиотек и внешних ресурсов.
- Данные хранить только в localStorage; ничего не отправлять в интернет.
- Сохранить три колонки «Фильмы», «Книги» и «Игры», компактные строки, проверку дублей, подтверждение удаления, участников, персональные галочки и оценки.
- Интерфейс и короткие подписи остаются на русском; страница удобна на телефоне шириной 375px, кнопки и поля не меньше 44px.
- Поиск не меняет сохранённые записи, а только их видимость; совпадение ищется в названии без учёта регистра.
- «Только неотмеченное» учитывает только галочку выбранного сейчас участника, а не отметки других членов семьи.
- «Сначала новые» сохраняет порядок добавления: последняя добавленная запись выше предыдущих. «По оценке» сортирует по средней оценке семьи от большей к меньшей; записи без оценки идут после оценённых.
- Случайный вариант выбирается из всех записей, которые не отмечены текущим участником, независимо от включённых поиска, фильтра и сортировки.

## Готово, когда
- На широком экране форма добавления находится в одну строку, а при ширине 375px её три элемента стоят друг под другом; кнопки и поля имеют высоту не менее 44px.
- Поиск без учёта регистра фильтрует записи одновременно во всех трёх колонках, а счётчики показывают число видимых записей.
- Включённый «Только неотмеченное» скрывает только записи, отмеченные выбранным участником, и его состояние сохраняется после F5.
- Доступны все три порядка сортировки; «Сначала новые» выбран по умолчанию, а выбранный порядок сохраняется после F5.
- Поиск, фильтр и сортировка работают вместе и не нарушают добавление, дубли, удаление, участников, галочки и оценки.
- Кнопка случайного выбора показывает одну неотмеченную текущим участником запись с возможностью получить ещё вариант, а при отсутствии таких записей — «Всё уже посмотрели!».
- Страница работает без интернета, а все новые сохраняемые настройки остаются после F5.
