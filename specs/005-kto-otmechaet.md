# Кто отмечает

## Для кого и зачем
Для семьи, в которой каждый участник отдельно отмечает просмотренные фильмы, прочитанные книги и сыгранные игры, ставит свои оценки и видит, что ещё не завершили все вместе.

## Что должно быть
- Можно добавить членов семьи по имени, например: «Айнур», «Муж», «Дочь».
- Вверху страницы можно выбрать, кто отмечает записи сейчас.
- У каждого участника свои галочки и оценки для каждой записи.
- Галочка и оценка выбранного участника изменяют только его данные.
- Оценка от 1 до 5 доступна участнику только после его галочки.
- У записи показывается средняя оценка семьи по оценкам участников, которые выставили оценку. Не выставленные оценки не участвуют в расчёте; если оценок нет, показывать «не оценено».
- Есть отдельный список «Вместе ещё не смотрели» со всеми записями, которые есть в основном списке, но хотя бы один член семьи ещё не отметил как завершённые. Внутри него записи сгруппированы по колонкам «Фильмы», «Книги» и «Игры»; подпись галочки в каждой колонке соответствует типу записи.
- Запись не попадает в список «Вместе ещё не смотрели», когда все члены семьи отметили её завершённой.
- Можно удалить члена семьи. При удалении исчезают его отметки и оценки; оставшиеся участники и их данные сохраняются. После удаления участника, выбранного сейчас, выбранным становится другой существующий участник.
- Если членов семьи ещё нет, интерфейс предлагает добавить первого участника; пока участников нет, персональные отметки и оценки не ставятся.
- Старые записи и оценки не теряются: при первом открытии новой версии они становятся отметками и оценками первого добавленного члена семьи. Если список участников в новой версии ещё не настроен, первый добавленный участник получает эти старые данные.
- Список членов семьи, выбранный участник, записи, отметки и оценки сохраняются в localStorage браузера после перезагрузки.

## Примеры
- Добавить «Айнур», «Муж» и «Дочь», выбрать «Айнур» и отметить фильм «Дюна»: галочка и оценка Айнур не меняют данные Мужа и Дочери.
- Если у «Дюны» Айнур поставила 5, а Муж — 3, средняя оценка семьи — 4. Если только Айнур поставила 5, показывается 5; если никто не оценил, показывается «не оценено».
- Если из трёх участников «Дюну» отметили только двое, она остаётся в «Вместе ещё не смотрели» в колонке «Фильмы». Когда её отметит третий участник, она исчезает из этого списка.
- Незавершённые всеми участниками книга и игра отображаются в «Вместе ещё не смотрели» соответственно в колонках «Книги» и «Игры».
- У старой записи «Дюна» с галочкой и оценкой 5 после обновления галочка и оценка принадлежат первому члену семьи; данные записи не теряются.
- Если удалить «Дочь», её отметки и оценки исчезают из данных, а отметки Айнур и Мужа остаются.

## Ограничения
- Использовать только HTML, CSS и JavaScript без библиотек и внешних ресурсов.
- Данные хранить только в localStorage; ничего не отправлять в интернет.
- Сохранить три колонки «Фильмы», «Книги» и «Игры», компактные строки, проверку дублей и подтверждение удаления записей.
- Интерфейс и короткие подписи остаются на русском; страница удобна на телефоне шириной 375px, кнопки и поля не меньше 44px.
- Галочки и оценки привязаны к участникам. Снятие галочки у выбранного участника удаляет только его оценку.
- Средняя оценка считается арифметически по оценкам от 1 до 5 только тех участников, которые поставили оценку; округлять до одной цифры после запятой. Если оценок нет, показывать «не оценено».
- Совместное завершение определяется галочками всех текущих членов семьи, независимо от наличия оценок. Удалённые участники больше не учитываются.
- При отсутствии хотя бы одного участника список «Вместе ещё не смотрели» не содержит записей до добавления первого участника.
- Старые общие галочки и оценки при миграции назначить первому добавленному участнику, остальные участники начинают без отметок и оценок.

## Готово, когда
- Можно добавить членов семьи, выбрать текущего участника вверху страницы и удалить участника.
- Отметки и оценки разных участников независимы, а снять галочку — значит удалить оценку только выбранного участника.
- Оценка отдельного участника доступна только после его галочки.
- Для записи показывается средняя оценка по выставленным оценкам с округлением до одного знака после запятой; при отсутствии оценок видно «не оценено».
- В «Вместе ещё не смотрели» показаны все записи, отмеченные не всеми текущими участниками, с группировкой по трём колонкам; запись исчезает после отметки всеми.
- Удаление участника удаляет его отметки и оценки, не меняя данные других участников.
- Старые записи, галочки и оценки перенесены первому члену семьи и остаются после перезагрузки.
- Участники, выбранный участник, записи, отметки и оценки сохраняются после F5.
- Страница работает без интернета и помещается на экране шириной 375px; элементы управления не меньше 44px.

- [x] Шаг 2. Добавить выбор текущего участника вверху страницы и сохранение участников/выбора. Пример: выбрать «Айнур», обновить страницу — выбрана «Айнур».
- [ ] Шаг 3. Перевести галочки на персональные данные участников и перенести старые галочки первому участнику. Пример: у двух участников для одной записи независимые галочки; старая галочка видна у первого после обновления.
- [ ] Шаг 4. Перевести оценки на персональные данные участников и перенести старые оценки первому участнику. Пример: у двух участников независимые оценки; старая оценка 5 видна у первого после обновления.
- [ ] Шаг 5. Показывать среднюю оценку семьи для записи. Пример: оценки 5 и 3 отображаются как 4; одна оценка 5 отображается как 5; без оценок видно «не оценено».
- [ ] Шаг 6. Добавить список «Вместе ещё не смотрели» с группировкой по трём типам. Пример: если из трёх участников запись «Дюна» отметили двое, она находится в колонке «Фильмы»; после отметки третьим исчезает.
- [ ] Шаг 7. Удалять персональные отметки и оценки вместе с участником и проверить сохранение всех данных. Пример: после удаления участника его оценка больше не входит в среднее, данные оставшегося участника сохраняются после F5.
