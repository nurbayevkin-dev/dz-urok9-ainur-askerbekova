# Компактные записи

## Для кого и зачем
Для семьи, которой нужно видеть больше записей в каждой колонке и быстро менять статус, оценку или удалять запись.

## Что должно быть
- Каждая запись отображается одной компактной строкой.
- В строке слева находится галочка, рядом название; справа — пять звёзд для оценки и маленькая кнопка ✕.
- Звёзды кликабельны для установки оценки от 1 до 5, когда запись отмечена галочкой.
- Пока галочка не установлена, звёзды серые и неактивные, рядом отображается «не оценено».
- Удаление записи по ✕ требует подтверждения с вопросом «Удалить?».
- На карточке не показывается метка типа и подпись «Оценка».
- Высота строки — не менее 44px; на экране шириной 375px все элементы строки помещаются.
- На мониторе в каждой колонке должны помещаться 10–15 строк без прокрутки.
- Логика галочек, оценок и сохранения остаётся прежней.

## Примеры
- Отмеченная запись без оценки показывает пять активных звёзд и «не оценено».
- При клике на четвёртую звезду отмеченная запись получает оценку ★★★★☆.
- У неотмеченной записи звёзды серые и на них нельзя нажать.
- При клике на ✕ появляется вопрос «Удалить?»; после подтверждения запись удаляется.
- На карточке фильма не показываются тип «Фильм» и подпись «Оценка», поскольку тип понятен по колонке.

## Ограничения
- Использовать только HTML, CSS и JavaScript без библиотек и внешних ресурсов.
- Не менять хранение данных в localStorage и существующую логику статуса и оценок.
- Интерфейс остаётся на русском; все интерактивные элементы должны быть удобны для телефона шириной 375px.

## Готово, когда
- Каждая запись занимает одну строку с галочкой, названием, пятью звёздами и кнопкой ✕.
- Строка имеет высоту не менее 44px, а содержимое помещается при ширине 375px.
- На мониторе в колонке помещается 10–15 строк без прокрутки.
- Метка типа и подпись «Оценка» отсутствуют.
- Без галочки звёзды серые и неактивные, рядом показано «не оценено»; с галочкой звёзды позволяют выбрать оценку.
- Перед удалением показывается «Удалить?», отмена сохраняет запись, подтверждение удаляет её.
- Галочки, оценки и записи продолжают сохраняться после перезагрузки.
