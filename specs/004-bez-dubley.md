# Без дубликатов

## Для кого и зачем
Для членов семьи, чтобы список в каждой колонке оставался понятным и одна и та же запись не появлялась там несколько раз.

## Что должно быть
- При добавлении проверять, есть ли в выбранной колонке запись с таким же названием.
- Сравнивать названия без учёта регистра.
- Если название уже есть, не добавлять новую запись и показать подсказку «Уже есть в списке».
- Одинаковые названия в разных колонках допустимы.
- После отклонённого добавления существующая запись и остальные данные списка остаются без изменений.

## Примеры
- Если в «Фильмах» уже есть «Дюна», попытка добавить «дюна» в «Фильмы» показывает «Уже есть в списке» и не создаёт запись.
- Если «Дюна» есть в «Фильмах», её можно добавить в «Книги».
- Если такого названия ещё нет в выбранной колонке, запись добавляется как обычно.

## Ограничения
- Сравнивать названия только внутри выбранной колонки и без учёта регистра.
- Не менять существующие правила хранения данных, статусов, оценок и сортировки.
- Использовать только HTML, CSS и JavaScript; данные остаются в браузере.
- Интерфейс остаётся на русском и удобен для телефона шириной 375px.

## Готово, когда
- Повтор названия в той же колонке (в том числе с другим регистром) не добавляется.
- При попытке добавить повтор показывается подсказка «Уже есть в списке».
- Такое же название можно добавить в другую колонку.
- Уникальные названия добавляются как раньше, а данные сохраняются после перезагрузки.
