# Семейный список

Локальная страница для семейного списка фильмов, книг и настольных игр. Записи сохраняются только в localStorage этого браузера.

## Что умеет

- Добавлять фильм, книгу или настольную игру по названию.
- Показывать записи в отдельных колонках «Фильмы», «Книги» и «Игры», с новыми записями сверху.
- Показывать отдельный счётчик записей для каждой колонки.
- Отмечать фильмы как «Просмотрено», книги как «Прочитано», а игры как «Играли».
- Разрешать оценку от 1 до 5 звёзд только для отмеченной записи; без оценки показывать «не оценено».
- Показывать записи компактными строками с галочкой, названием, звёздами и кнопкой удаления; тип определяется по колонке.
- Подтверждать удаление вопросом «Удалить?»; до отметки звёзды серые и неактивные.
- Переносить старые записи со статусом «готово» в отмеченное состояние, сохраняя оценку.
- Сохранять список и изменения после перезагрузки страницы.
- Работать без интернета; на телефоне шириной 375px колонки расположены друг под другом.

## Как проверить

Откройте `index.html` двойным щелчком. Добавьте «Дюна» (фильм), «Мастер и Маргарита» (книга) и «Каркассон» (настольная игра): каждая запись должна появиться в своей колонке, счётчики — обновиться, новые записи — оказаться сверху. Записи отображаются в одну строку без метки типа и подписи «Оценка». У «Дюны» отметьте «Просмотрено» и кликните по пятой звезде: должны отображаться ★★★★★. Пока запись не отмечена, звёзды серые и неактивные, рядом видно «не оценено». Нажмите ✕: вопрос «Удалить?» должен позволить отменить или подтвердить удаление. Обновите страницу клавишей F5 — список, галочки и оценки должны сохраниться. Попробуйте отправить пустое название: появится подсказка. Проверьте строки на ширине 375px и что на мониторе в колонках видно 10–15 записей без прокрутки.

Для проверки переноса старых данных откройте страницу с уже сохранённой старой записью со статусом «готово»: запись должна быть отмечена, а её оценка должна сохраниться.
