# Семейный список

Локальная страница для семейного списка фильмов, книг и настольных игр. Записи сохраняются только в localStorage этого браузера.

## Что умеет

- Добавлять фильм, книгу или настольную игру по названию.
- Показывать новые записи сверху со статусом «хочу».
- Менять статус на «готово» и ставить оценку от 1 до 5 звёзд.
- Показывать «не оценено», если оценка не задана.
- Сохранять список и изменения после перезагрузки страницы.
- Работать без интернета и на телефоне.

## Как проверить

Откройте `index.html` двойным щелчком. Добавьте «Дюна» (фильм), «Мастер и Маргарита» (книга) и «Каркассон» (настольная игра): появятся три записи с правильными типами, новые — сверху. У «Дюны» выберите статус «Готово» и оценку 5: должны отображаться статус и ★★★★★. У записей без оценки должно быть написано «не оценено». Обновите страницу клавишей F5 — список и изменения должны сохраниться. Попробуйте отправить пустое название: появится подсказка.
